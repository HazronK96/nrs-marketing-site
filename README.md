# News Release System — Marketing Site & Video Showcase

Marketing website and 60-second video package for **Group 27**'s Final Year Project:
**News Release System — Design and Implementation**, a gamer-first game-news platform.

🔗 **Live application:** https://fyp-nrs.geyser.host/

## What's in here

| File | Purpose |
|------|---------|
| `index.html` | The marketing website (open this in a browser) |
| `styles.css` | Styling for the site |
| `script.js` | Scroll animations |
| `showcase.html` | Auto-playing 60-second animated showcase — screen-record this to make the video |
| `VIDEO-SCRIPT.md` | Narration script, storyboard/shot list, and tagline options |

## How to run it

**No PHP, no server, no build step** — it's plain HTML/CSS/JS.

- **Easiest:** download the files into one folder and double-click `index.html`.
- **In VS Code:** install the *Live Server* extension, then right-click `index.html` → *Open with Live Server*.
- **Online:** published free via GitHub Pages (see below).

## The video

Open `showcase.html` full-screen (press `F11`) and screen-record one 60-second loop
with OBS, Windows Game Bar (`Win+G`), or macOS (`Cmd+Shift+5`). See `VIDEO-SCRIPT.md`
for the narration and shot list.

## Customise before you submit

1. **Tagline** — change `#tagline` in `index.html` and scene 1 in `showcase.html`
   (six options listed in `VIDEO-SCRIPT.md`).
2. **Team members** — fill the `.member` slots in the Team section of `index.html`.
